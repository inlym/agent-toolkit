# Git 操作授权规范

未经用户明确授权，禁止执行任何 Git 写操作。

## 禁止操作（未获授权时）

- `git commit`、`git push`
- 创建或合并分支
- 修改 Git 历史记录

## 允许操作

- 查看 Git 状态和代码变更
- 建议 Git 操作命令（但不执行）

## 视为明确授权的情形

- 用户明确要求提交或推送（如"提交代码"、"提交并推送代码"）
- 用户主动调用了提供该能力的技能（如 `good-commit`）

## 与提交类技能的配合

技能被触发即视为获得本次授权；技能流程执行完毕后，授权随之结束，不得顺势执行流程范围之外的 Git 操作。
